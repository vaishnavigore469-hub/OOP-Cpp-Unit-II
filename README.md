## List of Programs

### Program 01 - Basic Single Inheritance
Demonstrates single inheritance using a base class `Person` and a derived class `Student`.

### Program 02 - Protected Member Access
Demonstrates how a derived class can access a protected member of the base class.

### Program 03 - Public versus Private Inheritance
Demonstrates the difference between public and private inheritance and their effect on member accessibility.

### Program 04 - Multilevel Inheritance
Demonstrates multilevel inheritance using the hierarchy `Person → Employee → Manager`.

### Program 05 - Hierarchical Inheritance
Demonstrates hierarchical inheritance where `Car` and `Bike` are derived from a common `Vehicle` class.

### Program 06 - Multiple Inheritance
Demonstrates multiple inheritance by deriving the `Student` class from `Academic` and `Sports` classes.

### Program 07 - Multiple-Inheritance Ambiguity
Demonstrates how to resolve ambiguity when two base classes have functions with the same name using the scope-resolution operator.

### Program 08 - Constructor and Destructor Order
Demonstrates the order of execution of constructors and destructors in base and derived classes.

### Program 09 - Parameterized Base Constructor
Demonstrates how a derived class initializes a parameterized constructor of its base class using an initializer list.

### Program 10 - Function Overriding
Demonstrates function overriding using virtual functions and the `override` keyword in derived classes.

### Program 11 - Abstract Class
Demonstrates the use of an abstract class and a pure virtual function through different derived classes.

### Program 12 - Virtual Base Class and Diamond Inheritance
Demonstrates the use of a virtual base class to solve the duplicate-base problem in diamond inheritance.

### Program 13 - Friend Class
Demonstrates how a friend class can access private data members of another class.

### Program 14 - Nested Class
Demonstrates the creation and use of a class defined inside another class.

### Program 15 - Vehicle Rental System
Demonstrates an inheritance-based vehicle rental system using different vehicle types, rent calculation, and function overriding.
